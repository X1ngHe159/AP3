? 操作说明

鼠标

  • 左键拖拽 环绕旋转视角
  • 滚轮 缩放（拉近 / 拉远）
  • 单击（无拖拽） 颜色编码拾取物体：选中高亮 + 面板切换到该物体材质
  • 右键拖拽 平移环绕中心（target）

键盘

  • 1 / 2 / 3 着色模型：Phong / Blinn-Phong / Toon
  • A / D / S 环境光 / 漫反射 / 镜面三分量开关
  • L 方向光（太阳）开关
  • P 点光开关
  • H 阴影开关
  • N 法线贴图开关
  • C 环境贴图开关
  • T 纹理开关
  • X 三联分屏对比（Phong / Blinn-Phong / Toon）
  • F 线框模式
  • O 正交 / 透视投影切换
  • R 重置视角
  • 空格 暂停 / 继续动画（太阳缓慢移动 + 自动环绕）

无法启动场景
